MedML Training Dashboard

A managed interface for medical image ML workflows on AWS

Research Use Only

This platform is for research and development purposes. Models trained and deployed here are not validated for clinical use. Clinical deployment requires regulatory clearance (FDA, CE marking), clinical validation studies, and qualified human oversight. AI predictions must not be used as the sole basis for medical decisions.

AWS Configuration
Connect via environment credentials or explicit keys. Browse S3 buckets and manage access to SageMaker.
Data
Browse S3 buckets and explore your raw and processed medical imaging datasets.
Fairness & Demographics
Scan DICOM files to extract patient demographics — sex, age, ethnicity — and visualise distribution for bias auditing.
Model Training
Launch SageMaker BYOC training jobs for classification (ResNet50, DenseNet121, ViT, EfficientNet) and segmentation (SegResNet, SwinUNETR, UNet) with MLflow and TensorBoard tracking.
Deployment
Deploy trained models to SageMaker real-time or async endpoints. Track endpoint status and manage the full lifecycle from the dashboard.
Inference
Invoke deployed endpoints with DICOM or NIfTI inputs via S3 URI or direct file upload. View classification probabilities and segmentation mask statistics.
Evaluation
Run SageMaker Processing Jobs to evaluate endpoints on labeled test sets. Generates ROC-AUC, confusion matrix, per-class metrics, and demographic subgroup performance.
Monitoring
Enable data capture on endpoints, create data quality baselines, and schedule automated monitoring jobs to detect data and model quality drift in production.

Supported Tasks

Classification
  • 2D DICOM / PNG / JPEG inputs
  • Class-named subfolders (train/ val/ test/)
  • ResNet50, VGG16, EfficientNet, DenseNet121, ViT
  • Outputs: model.tar.gz with inference.py bundled
Segmentation
  • 3D NIfTI volumes (img.nii.gz + mask.nii.gz)
  • Binary segmentation (0/1 masks)
  • SegResNet, SwinUNETR, UNet
  • HU clipping [-100, 500] for CT

Quick Start

  1. Go to AWS — connect with your credentials or use ~/.aws/credentials
  2. Go to Fairness — scan your dataset for demographic distributions
  3. Go to Training — select a model, configure a SageMaker job, and launch
  4. Go to Deployment — deploy the trained model to a SageMaker endpoint
  5. Go to Inference — test the endpoint with a sample DICOM
  6. Go to Evaluation — run a full evaluation job with metrics and plots
